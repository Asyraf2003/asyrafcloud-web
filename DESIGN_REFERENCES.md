# Design references — cinematic rebuild

The primary references are **Lusion** and **Lando Norris / OFF+BRAND**. This version is based on the owner's actual screen recordings, with time-indexed observations and an area-by-area implementation map in [the rebuild reference study](docs/rebuild/REFERENCE_STUDY.md).

The first version's small 3D icon, advertising-style project posters, conventional grid, and toy workspace were removed. The new composition uses a full-scale sculptural opening, a serif/sans identity chapter, viewport project stages, empty layered media canvases, a spatial personal environment, and a dark inset closing stage.

All geometry and rendering code are original. No reference-site assets, logos, audio, copy, or 3D models are reused. Empty media is intentional and configured in `dist/content.js`.
